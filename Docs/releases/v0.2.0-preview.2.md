## Experimental Windows preview 2

Download **sotc-v0.2.0-preview.2-windows-x64.zip** below. No compilation, Visual Studio, Python, CMake,
or Ninja is required. The Microsoft C++ runtime DLLs are included.

### What's new since preview 1

- Faster VU1 emulation: compiled VU1 programs use cheaper exact checks, about 10% less VU work per frame.
  In a heavy canyon scene this measured roughly 37 → 41 emulated fields/s with pacing off. Results are
  bit-identical to before; heavy scenes are still below full speed on mid-range CPUs.
- Frame limit: with `SOTC_VSYNC=0` the window now presents up to `SOTC_FPS_LIMIT` frames per second
  (default **360**, `0` = uncapped) instead of a fixed 120. This does not change the game's own update rate.
- Performance overlay: press **F3** to show host FPS and frame times, the game's real update rate
  (`Game`), the emulated field rate (`VBlank`) and new GPU frames. `PS2X_PERF_OVERLAY=1` shows it at startup.
- Updated PS2Recomp runtime with upstream fixes (float semantics, SIF syscalls, resume points), with the
  port's EE float behavior kept so movement and animation match preview 1.

Existing `sotc.ini` files keep their values; missing settings such as `SOTC_FPS_LIMIT` are added on first launch.

### How to play

1. Extract the entire release ZIP into a writable folder.
2. Put your own supported `.iso` in its `Game` folder.
3. Double-click `Play.bat`.

You can also keep the ISO elsewhere and drag it onto `Play.bat`. The ISO must remain available while playing.
The game validates its boot executable and module hashes, then reads assets directly from your disc image.

Use the Windows ZIP attached to this release. GitHub's automatic **Source code** downloads are for developers.

To update from preview 1, extract this ZIP to a new folder and copy your `memcards`, `states`, and `sotc.ini`
into it.

### Requirements

- Windows 10 or 11, 64-bit.
- An AVX2-capable CPU and a GPU with OpenGL 4.6 support.
- Your own **Shadow of the Colossus (Europe, Australia), SCES-53326, version 1.00 (PAL)** disc image.
  Other regions, later revisions, and modified or trimmed images are unsupported.

Supported ISO size: **4,635,918,336 bytes**. ISO SHA-256:

```text
068925770645266189005f09c9a9a1fee25726bfc93c89b12f832f3673664ac4
```

The ZIP contains no ISO, extracted game assets, BIOS, personal settings, or saves.

### Controls and settings

- Move: **W A S D**; camera: **mouse**.
- Jump: **F**; attack: **left mouse**; draw weapon/dismount: **right mouse**.
- Grab: **left Shift**; whistle/mount: **Space**; focus: **Q**.
- Start: **Enter**; fullscreen: **F11**; save/load state: **F5 / F9**; performance overlay: **F3**.

Gamepads are supported. `sotc.ini` is created on first launch. See `Docs/CONFIGURATION.md` in the ZIP for
settings. Keep `memcards`, `states`, and `sotc.ini` when updating to another release.

### Known issues

This is an experimental fan project. Heavy scenes such as large outdoor areas can run below full speed;
the F3 overlay's `Game` and `VBlank` values show when that happens. Occasional black frames, brief first-use
shader compilation stalls, and imperfect audio can occur. If the game exits, `Play.bat` keeps its error
visible. Report the error, your CPU/GPU details, and `BUILD-INFO.txt` through
[Issues](https://github.com/LightVelox/sotc-vibe-pc/issues).

The `.zip.sha256` attachment contains the checksum of the downloadable ZIP, not the ISO checksum above.
